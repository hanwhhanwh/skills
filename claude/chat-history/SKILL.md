현재 Claude Code 세션의 transcript(대화 기록 JSONL 파일)에서 사용자가 입력한 프롬프트를 추출해 마크다운 표로 저장합니다.

## 입력 처리

- 인자가 없으면 저장할 파일 경로를 요청하고 작업을 진행하지 않습니다.
- 대상 파일이 이미 있으면 덮어써도 되는지 확인을 받은 뒤 진행합니다.
- 상위 디렉터리가 없으면 추측해서 만들지 말고 사용자에게 확인합니다.

## 절차

1. 아래 명령으로 표를 생성합니다. `python`이 없으면 `python3`을 사용합니다.

   ```bash
   python "${CLAUDE_SKILL_DIR}/scripts/chat_history.py" "<저장할 파일 경로>" "${CLAUDE_SESSION_ID}"
   ```

2. 생성된 파일을 읽어 프롬프트 수와 내용이 현재 세션과 맞는지 확인합니다. 이 스킬을 실행한 프롬프트(`/chat-history ...`)가 마지막 행에 포함되는 것이 정상입니다.
3. 프롬프트 안에 비밀번호, 접속 키, 개인정보처럼 보이는 내용이 있으면 해당 내용을 인용하지 말고 어떤 종류의 정보인지만 알린 뒤, 마스킹 여부를 사용자에게 묻습니다.
4. 스크립트가 출력한 요약(파일 경로, 프롬프트 수, 토큰 합계)을 그대로 보고합니다.

## 출력 형식

| No | 입력 시각 | 사용자 입력 내용 | Input 토큰 | Output 토큰 |
|---:|---|---|---:|---:|
| 1 | 2026-11-17 09:12:31 | 프롬프트 내용 | 46,876 | 190 |

- 입력 시각은 로컬 시간대 `YYYY-MM-DD HH:MM:SS`로 표기합니다.
- 줄바꿈은 `<br>`, `|`는 `\|`로 바꿔 표 안에 넣습니다.
- 토큰은 해당 프롬프트부터 다음 프롬프트 직전까지 호출된 API 사용량의 합입니다. Input은 input + cache 생성 + cache 읽기, Output은 output 토큰입니다. 서브에이전트 사용량은 포함하지 않습니다.
- 시스템이 넣은 메시지(도구 결과, 작업 알림, 컨텍스트 요약, 로컬 명령 출력)는 제외하고, 슬래시 명령은 `/명령 인자` 형태로 표시합니다.
